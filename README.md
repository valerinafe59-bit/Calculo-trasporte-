# 🛠️ Ferramenta de Cálculo de Transporte

Este repositório contém a ferramenta principal no ficheiro compactado **Cálculo-transporte-principal.zip**.

---

## 🎯 Objetivo da Ferramenta

A ferramenta é utilizada para **calcular custos e definir rotas de transporte**.

## 🚀 Como Utilizar

Basta descompactar o ficheiro **Cálculo-transporte-principal.zip** para ter acesso a todos os arquivos da aplicação.
